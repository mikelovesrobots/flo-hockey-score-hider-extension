# FloHockey Score Hider

A Chrome extension that automatically hides the score display on FloHockey.tv to prevent spoilers when watching games that have already started.

![Screenshot 2025-05-01 at 11 14 22 PM](https://github.com/user-attachments/assets/a145e12d-a63a-4cb1-84c7-b333d47a121e)

## Problem

When watching a game on FloHockey.tv that's already in progress, the current score is prominently displayed on the page. This can spoil the game if you're starting to watch a few minutes late.

## Solution

FloHockey Score Hider automatically hides the score display, allowing you to enjoy the game without knowing the current score.

## Features

- Automatically hides the score display on FloHockey.tv
- Works on both live and archived games
- Clean, unobtrusive interface
- No configuration needed
- Lightweight and privacy-focused

## Installation

1. Download the latest release from the [releases page](https://github.com/mikelovesrobots/flo-hockey-score-hider-extension/releases)
2. Unzip the downloaded file
3. Open Chrome and go to `chrome://extensions/`
4. Enable "Developer mode" in the top right
5. Click "Load unpacked"
6. Select the unzipped extension folder

## How It Works

The extension:

1. Detects when you're on a FloHockey.tv page
2. Automatically hides the score display
3. Shows a placeholder indicating where content has been hidden
4. Works entirely locally in your browser
